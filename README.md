## ✨ Features

-   **📸 Post on the Go:** meaningful moments don't wait. Upload photos, add captions, and publish gallery items to your site instantly.
-   **🔒 Secure by Design:** User configurations (API keys, endpoints) are stored locally in an **LMDB** database, encrypted at rest using **AES-GCM-SIV**.
-   **🔧 Fully Configurable:** define your API endpoint and auth keys directly through the bot. No hardcoded secrets.
-   **⚡ Async & Fast:** Built on top of `tokio` and `teloxide` for high performance and low resource usage.

## 🚀 Getting Started

### Prerequisites

-   **Rust Toolchain:** Ensure you have Rust installed (latest stable).
-   **Telegram Bot Token:** Create a bot via [@BotFather](https://t.me/BotFather) and get your token.
-   **Private Key:** A secret string used to encrypt the local database.

### Environment Variables

You can configure `telecontrol` using environment variables or CLI arguments.

| Variable | Description |
|----------|-------------|
| `TC_BOT_TOKEN` | Your Telegram Bot Token (or `BOT_TOKEN`) |
| `TC_PRIVATE_KEY` | Key for encrypting local user data (or `PRIVATE_KEY`) |

### Running the Bot

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/telecontrol.git
    cd telecontrol
    ```

2.  **Run with cargo:**
    ```bash
    # Generate a private key if you don't have one
    cargo run -- privkey

    # Start the bot
    export TC_BOT_TOKEN="your_bot_token"
    export TC_PRIVATE_KEY="your_generated_private_key"
    cargo run
    ```

    *Alternatively, pass arguments directly:*
    ```bash
    cargo run -- start --token "YOUR_TOKEN" --privkey "YOUR_KEY" --database "./my_db.lmdb"
    ```

## 🤖 Bot Commands

Once your bot is running, find it on Telegram and use these commands:

| Command | Description |
| :--- | :--- |
| `/start` | Wake up the bot and get things moving. |
| `/setkey` | Securely set your Post Authorization Key for the API. |
| `/setapi` | Configure the target API endpoint (HTTP/HTTPS). |
| `/post` | Start the interactive posting flow (Gallery mode). |
| `/help` | Show the help menu. |

## 🛠️ Usage Workflow

1.  **Setup:** Run `/setapi` to tell the bot where your website's API lives.
2.  **Auth:** Run `/setkey` to provide the authentication token your API expects.
3.  **Post:**
    -   Run `/post`.
    -   Select **Gallery**.
    -   Send a photo (with a caption!).
    -   The bot will ask you to review the draft.
    -   Confirm with **Good**, and boom—it's live! 🚀
